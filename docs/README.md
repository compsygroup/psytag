# Introduction

<h2 align="center">Psytag: Toolbox for Behavioral Annotations</h2>

**Psytag is the open-source toolbox for behavioral data annotation and labeling.** Psytag  makes it easy to annotate video, image, audio, and text (coming soon) data commonly used in behavioral, social, and medical sciences.

{% hint style="info" %}
New to Psytag? Check out the [installation](overview/installation.md) and [getting starting](overview/getting-started.md) guides
{% endhint %}

Psytag gives you all tools you need to start your data annotations, and they are all open-source and free.

* Data, task, annotator, and annotation management backends&#x20;
* Automated task-annotator assignment and coordination workflows
* Automated adjudication control and management
* Ready to use interfaces tailored for behavioral data

Psytag can run on any computer and OS that can run docker containers.&#x20;
