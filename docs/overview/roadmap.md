# Roadmap

## Roadmap <a href="#contributing" id="contributing"></a>

Psytag is continually evolving, with our team actively working on new features and enhancements. Given our limited resources, prioritization is key. Below are the current priorities for improvement, which we will keep updating as needed.

### Core Developments

We plan to implement the following updates over the next year:

* [ ] Develop more annotation interfaces for current media types (video, audio, image), such as video/image segmentation and object annotation.
* [ ] Add support for more media types, such as text and wearables.
* [ ] Improve adjudication workflows
* [ ] Make visual layouts more adaptive and flexible

### Community Developments

We constantly look forward to new feature suggestions and implementations from the community. There are many things you can contribute to. You can, for example, develop your own annotation interface and share with us.&#x20;
